# Interview booking rules

Edit this file freely — it is yours, not the app's. The agent reads it before proposing any interview slot and writes learned corrections back into it.

## Defaults (change what's wrong)

- **Working hours**: 09:00–17:00, Mon–Fri, in the user's local timezone.
- **No interviews before 10:00.** Mornings are for real work.
- **Lunch is blocked**: 12:00–13:00.
- **Minimum notice**: 24 hours. Never offer a slot sooner unless the user asks for it explicitly.
- **Default length**: 30 minutes for a phone screen, 45 for a full interview.
- **Buffer**: 15 minutes either side of an existing event; never propose back-to-back with an external meeting.
- **Slot offers expire** after 48 hours; a slot held for one candidate is not offered to another until it expires.
- **Fridays after 15:00**: avoid.

## Learned

The agent appends corrections here, dated, in the user's words. Example:

- 2026-07-28 — "No interviews on Wednesdays, that's my delivery day."
