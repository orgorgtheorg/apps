# Watchlist

The pages the watchdog checks each hour. Keep it short — three pages that matter beat twenty that don't.

| Slug    | URL                         | Must be true                                       |
| ------- | --------------------------- | -------------------------------------------------- |
| home    | https://example.com/        | Page loads and the phone number appears            |
| booking | https://example.com/booking | The "Book now" button exists and its link resolves |
| contact | https://example.com/contact | The contact form renders                           |

"Must be true" is checked literally each hour — write it as something you could verify by looking at the page, not as a feeling.
