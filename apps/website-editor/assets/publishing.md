## Rules

- Publishing is always an explicit, confirmed action naming the version.
- DNS changes and domain purchases are separate confirmations, taken one at a time, immediately before the action.
- After every publish: verify the live URL serves the new version, screenshot it, and only then mark it published.
- If a publish fails, the previous version stays live and the failure is reported with the actual error.
