# Renewals

Annual and multi-year commitments the agent should warn about. The **cancel-by** date is renewal date minus the notice period — that's the one that costs money to miss.

| Vendor | Annual cost | Renews on | Notice period | Cancel by | Source |
| ------ | ----------- | --------- | ------------- | --------- | ------ |
|        |             |           |               |           |        |

Source = where the date came from (invoice, contract PDF, the vendor's billing page). A row without a source is a guess and should be verified before it drives an alert.

If the `renewal-tracker` app is installed, it owns this data — this file stays empty and the agent reads its registry instead.
